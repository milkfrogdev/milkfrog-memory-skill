# Memory Snapshot Sync RUNBOOK ({{SCHEDULE_TIME}} Cron / Manual Run)

Your job: incrementally distill changed memory entries into compact `AGENTS.md` hot snapshot caches in strict order: **Stage 1: Per-Workspace -> Stage 2A: Global Workspaces Block -> Stage 2B: Global Memory Blocks**. The Python script handles hashing, diffs, section merging, schema checks, backups, and writes; your job is to update only the changed content accurately.

Tool: `{{PYTHON_CMD}} "{{OPS_DIR}}/memsync.py" <command>` (`memsync` below).
Stdout returns compact ASCII status only; read generated report files to inspect full details.

## Hard Prohibitions
1. Never edit `{{MEMORY_HOME}}/AGENTS.md` or any `<workspace>/AGENTS.md` directly; `memsync apply` is the sole writer.
2. Never modify `GEMINI.md`, `memories/*.md`, `config.json`, or `sync-state.json` during snapshot sync.
3. Write draft files strictly inside `{{OPS_DIR}}/work/`.
4. Never copy secrets, API keys, tokens, or `sync: never` sensitive internals into any `AGENTS.md` (and never bypass `memsync` to read raw `sync: never` files).

## Anti-Hallucination, Formatting & Shrinkage Rules
1. **Verify full text before guessing**: Whenever a diff is ambiguous, edits a long single-line list, involves `[DELETED]` entries, or needs full workspace context, run the read-only inspect commands first (they work across all registered workspaces with zero extra folder permissions and strictly redact `sync: never` bodies), then read the generated report:
   - `memsync show <scope> <file> [--version current|before|both]` (supports memory entries as well as `AGENTS.md` / `GEMINI.md`)
   - `memsync search <query> [--scope all|<id>]` (searches current and cached pre-delete entries across scopes)
2. **Never invent replacement relationships from co-occurring deletes and adds**: If one line or batch removes item A and adds item B (even when a total count stays unchanged), **do NOT claim "B replaced A" or "upgraded A to B"** unless the memory body explicitly states a replacement. State them separately ("removed A; added B") in both `AGENTS.md` and the final summary.
3. **Hold the final summary to the same factual bar**: Only state changes directly supported by inspected memory bodies and diffs; never extrapolate for smoother prose.
4. **Structured per-item formatting (never jam unrelated items onto one line)**: Give every distinct project, workstream, or convention its own short bullet (split large active projects into a summary line plus 2-4 concise sub-bullets). Clean per-item lines keep snapshots readable and make line-level diffs precise.
5. **Auto-shrink explicitly completed/archived items**: When a changed memory entry explicitly states that a project/phase is completed, archived, or retired, strip obsolete intermediate hashes/test counts/dev gotchas from `AGENTS.md` and condense it to a 1-2 line final-status pointer; leave untouched historical items as-is.

## Execution Steps

### Step 1 · Lint Check
Run `memsync lint` and read `work/lint-<today>.md`. Note any ERROR/WARN for the final report; warnings do not block sync unless `apply` fails.

### Step 2 · Build Incremental Sync Plan
Run `memsync sync-plan` and read `work/sync-plan-<today>.md`:
- If index-only mode (`SKIP_ALL`) or all scopes show `SKIP`, exit with the SKIP summary immediately. Never rewrite unchanged files.
- Skip Stage-1 draft/apply for any workspace marked `SKIP_AGENTS` (`sync_mode=index`).

### Step 3 · Stage 1: Process Changed Workspaces
For each workspace `<ws>` marked `NEEDS_UPDATE`:
1. Read `work/sync-ws-<ws>-<today>.md` (if flagged `FOREIGN_AGENTS`, keep original memory entries untouched and warn the user in the final report to review the `backup/` copy).
2. Merge current `AGENTS.md` with `[NEW]`, `[MODIFIED]`, and `[DELETED]` diffs into `{{OPS_DIR}}/work/draft-ws-<ws>-<today>.md` using these fixed sections:
   - Header note: auto-generated by memory sync ({{SCHEDULE_TIME}} / manual), do not edit manually, workspace name + root path anchor, sync date;
   - Pointers to `<workspace>/GEMINI.md` and `{{MEMORY_HOME}}/GEMINI.md`;
   - `## 1. Active Project Progress & Decisions` (active `project` state; one bullet per project; prune deleted items and condense explicitly completed/archived ones);
   - `## 2. Project-Specific Conventions & Pitfalls` (repo-specific constraints only; never duplicate global rules).
3. Run `memsync apply --scope <ws> "{{OPS_DIR}}/work/draft-ws-<ws>-<today>.md"` and read `apply-<ws>-<today>.md` to confirm `ERROR 0`.

### Step 4 · Stage 2: Section-Level Rollup to Global `AGENTS.md`
If `[global]` is marked `NEEDS_UPDATE`, follow `stage2_ws` and `stage2_mem` from `sync-plan` (untouched sections are preserved verbatim by `memsync apply --section` and the header sync date is refreshed automatically):

#### Stage 2A · Workspaces Sync Block (run when `stage2_ws=yes`)
1. Run `memsync global-input --part ws` and read `work/sync-global-ws-<today>.md` (`[UNCHANGED]` stays as-is; updated workspaces show incremental diffs; `sync_mode=local` workspaces appear as `[ISOLATED]` and must keep only a one-line locator with zero internal progress leaked).
2. Using the workspace changes already inspected in Stage 1, draft **only Section 2 (`## 2. Workspaces & Active Projects`)** to `{{OPS_DIR}}/work/draft-global-ws-<today>.md` (keep each workspace and major project on its own bullet).
3. Run `memsync apply --scope global --section 2` (add `--no-copy` if `stage2_mem=yes` so cross-tool mirroring runs once after Stage 2B; `memsync` updates workspace baselines while keeping global memory diffs pending for 2B) and confirm `ERROR 0`.

#### Stage 2B · Global Memory Sync Blocks (run when `stage2_mem=yes`)
1. Run `memsync global-input --part mem` and read `work/sync-global-mem-<today>.md` (contains global memory diffs, current sections, and suggested `--section` list).
2. Draft **only the affected numbered sections** to `{{OPS_DIR}}/work/draft-global-mem-<today>.md` (`1`=`user`, `2`=workspaces + global `project`, `3`=`feedback`, `4`=`reference` ending with the pointer to `memories/local-installed-tools.md` when it exists; keep `sync: never` redacted).
3. Run `memsync apply --scope global --section <e.g. 1,3,4> "{{OPS_DIR}}/work/draft-global-mem-<today>.md"` and confirm `ERROR 0` (also triggers cross-tool mirroring if enabled; for initial creation or full reformatting, use `global-input --part all` and `apply --scope global <full-draft>` without `--section`).
