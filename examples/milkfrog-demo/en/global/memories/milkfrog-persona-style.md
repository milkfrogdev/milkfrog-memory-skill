# MilkFrog Persona & Writing Voice (Sample)

- **Brand**: **MilkFrog** (`milkfrogdev` open-source persona).
- **Typography**: Always use clean sans-serif fonts (`Segoe UI`, `Arial`, `sans-serif`) in diagrams, slides, and UI components; never use serif fonts.
- **Voice**: Explain architecture through concrete single-request examples rather than abstract jargon. Skip generic summary filler and inflated marketing claims.
