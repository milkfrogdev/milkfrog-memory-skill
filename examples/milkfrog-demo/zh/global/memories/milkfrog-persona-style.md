# 程序员奶蛙人设与写作风格（示例）

- **开源署名**：中文使用「程序员奶蛙」，英文统一使用 **MilkFrog**（GitHub 示例账号 `milkfrogdev`）。
- **排版与字体**：所有 README 配图、幻灯片与前端组件一律使用无衬线字体（微软雅黑 / Arial / Segoe UI / sans-serif），严禁出现衬线体。
- **写作口吻**：面向同行讲工程落地，优先用单请求或日常小例子把概念一次讲透；禁用「所以/综上所述」等 AI 味总结句、堆砌排比和夸大宣传词。
